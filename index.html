How to Host on GitHub Pages

Follow these 3 quick steps to give your wife her custom live URL (e.g., yourname.github.io/happy-birthday).

  1. Create a GitHub Repository: Sign in to GitHub, click New Repository, name it (e.g. happy-birthday) and set it to public.
  2. Upload Your Files: Upload this index.html file along with the photo files (PXL_2026...) and video file birthday_tribute.mp4.
  3. Turn on GitHub Pages: Go to Settings → Pages (on left sidebar) → under Branch select main and click Save.

Within 1-2 minutes, GitHub will publish your live romantic website link to share with her!
